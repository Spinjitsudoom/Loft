**The Windows server now has a setup.** Download `loft-server-0.1.3-windows-x64-setup.exe` and run it:

- It installs just for you, with no administrator needed, into `%LOCALAPPDATA%\Programs\Loft Server`.
- **Loft Server** and **Open Loft** are added to the Start menu. You can choose to have Loft start when you sign in to Windows.
- It appears in Windows' list of installed apps, with an uninstaller. Uninstalling leaves your library's data (`%LOCALAPPDATA%\Loft`) where it is.
- From here on, it updates itself the same way as before (Library settings → Loft version → Restart to update), by running the next setup for you.

The first time, Windows may say it protected your PC: choose **More info**, then **Run anyway**.

**Rather unzip it?** `loft-server-0.1.3-windows-x64.zip` is still here, and copies unpacked from a zip keep updating from the zip.

**Coming from 0.1.2?** Your server, desktop app and Loft Lite offer this update by themselves. To move a Windows server from the zip to the setup, stop it, run the setup, and start it from the Start menu. Your library, sign-ins and settings are kept, because they live in `%LOCALAPPDATA%\Loft`, not in the program's folder. If you made a `config.toml`, copy it into the new folder.

Everything else is as in [0.1.2](https://github.com/Spinjitsudoom/Loft/releases/tag/v0.1.2).
