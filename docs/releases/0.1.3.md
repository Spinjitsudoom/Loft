**Loft Server for Windows now has a setup, and runs in the background with an icon by the clock.**

Download `loft-server-0.1.3-windows-x64-setup.exe` and run it:

- It installs just for you, with no administrator needed, into `%LOCALAPPDATA%\Programs\Loft Server`.
- **Loft Server** and **Open Loft** are added to the Start menu.
- Loft Server runs without a console window. **Click its icon** by the clock to open Loft in your browser. **Right-click it** for:
  - the address your phone and other computers use
  - **Update**, when a new version is ready
  - **Start with Windows**, which is on from the first start
  - **Open the data folder**
  - **Restart the server**
  - **Quit**
- If the server stops by itself, Loft Server starts it again.
- What the server says is written to `%LOCALAPPDATA%\Loft\server.log`. Settings that aren't in the web app go in `%LOCALAPPDATA%\Loft\config.toml`.
- It appears in Windows' list of installed apps, with an uninstaller. Uninstalling leaves your library's data (`%LOCALAPPDATA%\Loft`) where it is.
- From here on it updates itself by running the next setup for you: choose **Update** in the tray menu, or **Restart to update** in Library settings.

The first time, Windows may say it protected your PC: choose **More info**, then **Run anyway**. Allow Loft through the firewall so other devices can reach it.

**Rather unzip it?** `loft-server-0.1.3-windows-x64.zip` holds the same **Loft Server.exe**. Copies unpacked from the zip keep updating from the zip.

**Coming from 0.1.2?** Your server, desktop app and Loft Lite offer this update by themselves. To move a Windows server from the zip to the setup, quit it, run the setup, and start Loft Server. Your library, sign-ins and settings are kept.

Everything else is as in [0.1.2](https://github.com/Spinjitsudoom/Loft/releases/tag/v0.1.2).
