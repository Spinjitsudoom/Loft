**On Windows, Loft Server always runs in the tray now.**

The first 0.1.3 setup started Loft in a console window, and its shortcuts kept doing so after the
tray arrived. From this version on, opening `loft-server.exe` by double-clicking it, or from one of
those old shortcuts, starts **Loft Server** in the tray and closes the console. Typed in a
terminal, `loft-server.exe` still runs there, as before.

**What's new opens in Loft.** After an update, Loft shows what changed in a pop-up, once. It's in
**Your settings** any time, and before you update, **Library settings** shows the new version's notes.

**Have a Windows server from 0.1.3?** It offers this update by itself: choose **Restart to update**
in Library settings, or **Update** in the tray menu. After the update Loft runs from the tray. Your
library, sign-ins and settings are kept.

**New to Loft on Windows?** Download `loft-server-0.1.4-windows-x64-setup.exe` and run it. What
the tray does is described in [0.1.3](https://github.com/Spinjitsudoom/Loft/releases/tag/v0.1.3).

Everything else is as in [0.1.3](https://github.com/Spinjitsudoom/Loft/releases/tag/v0.1.3).
