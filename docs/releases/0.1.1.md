The first release of **Loft**, a self-hosted ebook library with pages that turn like paper. Your books stay where they are; Loft reads them, shelves them, and lets everyone you invite read them on a phone, tablet or computer.

## What to download

**The server** runs on the computer that holds your books. It needs nothing else installed.

| System | File |
| --- | --- |
| Windows (64-bit) | `loft-server-0.1.1-windows-x64.zip` |
| macOS (Apple silicon) | `loft-server-0.1.1-macos-arm64.zip` |
| Linux (64-bit) | `loft-server-0.1.1-linux-x64.tar.gz` |
| Docker | `docker compose up -d` from the source ([docs/docker.md](https://github.com/Spinjitsudoom/Loft/blob/master/docs/docker.md)) |

Unpack it and start `loft-server` (`loft-server.exe` on Windows), then open http://localhost:4545. The first person to open it creates the admin account and chooses the books folder in Library settings. The README.txt inside says more.

**The apps** open your Loft server from another device. You can also just use a browser.

| Device | File |
| --- | --- |
| Android | `loft-lite-0.1.1.apk` |
| Windows | `Loft-Setup-0.1.1.exe` |
| macOS (Apple silicon / Intel) | `Loft-0.1.1-mac-arm64.dmg` / `Loft-0.1.1-mac-x64.dmg` |
| Linux | `Loft-0.1.1-linux-x86_64.AppImage`, or `loft_0.1.1_amd64.deb` / `loft-0.1.1.x86_64.rpm` |

## The first time you open them

These builds aren't signed with a paid Apple or Microsoft certificate, so each system asks once:

- **Windows** says it protected your PC: choose **More info**, then **Run anyway**.
- **macOS app**: open it once, then go to **System Settings → Privacy & Security** and choose **Open Anyway**.
- **macOS server**: in Terminal, inside the unpacked folder, run `xattr -dr com.apple.quarantine .` once, then `./loft-server`.
- **Android**: allow your browser or file manager to install apps when it asks.
- **Linux AppImage**: make it executable (`chmod +x`), then run it.

`SHA256SUMS.txt` lists every file's checksum.

## What's in it

- **A library that looks like one**: a cover wall at home, and the stacks, with books spine-out on bookcases by series, section or author. **Previous** and **Next** on a book's page step through the list you came from.
- **A reader that turns like paper**: comics and PDFs page by page (two-page spreads, manga right to left, split scans), and EPUB, Kindle (MOBI/AZW/AZW3) and FB2 laid out to your font and size.
- **For several people**: each with their own place, bookmarks and shelves. Members can submit books for approval, ask for books, and discuss them without spoilers.
- **Offline reading**: download a book and read with no connection, and your place catches up later.
- **Managing the library**: edit details and covers, look them up in Google Books, Open Library, Hardcover, ISBNdb and AniList, and run a library check. New books with missing details are filled in automatically from sure matches, and you can undo it.

## Known limits

- The standalone server for macOS is for Apple silicon. On an Intel Mac, run it from source or with Docker.
- Loft doesn't update itself. New versions appear on this page.
- It's meant for your home network (or Tailscale), not the open internet.
