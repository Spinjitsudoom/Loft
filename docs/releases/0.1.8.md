**Windows: updating works again.**

On Windows, choosing **Restart to update** in Library settings (or **Update** in the tray icon's menu) closed Loft Server and left it closed, still on the old version. Now the new version installs and Loft Server starts again by itself.

- Loft keeps running while the update gets going. The setup closes it, installs the new version and starts it again.
- If the update can't start, Loft stays running as it was. What the setup did is written to `%LOCALAPPDATA%\Loft\update-setup.log`.
- Library settings no longer says an update is still downloading after Loft was closed in the middle of the download.

**If your Windows server is on 0.1.7 or older, install this update by hand once.** The broken part is in the copy you have now, so it can't update itself to this version:

1. Download `loft-server-0.1.8-windows-x64-setup.exe` below.
2. Run it. Your library, settings and books stay as they are.

After that, updates install by themselves again.

Everything else is as in [0.1.7](https://github.com/Spinjitsudoom/Loft/releases/tag/v0.1.7).
