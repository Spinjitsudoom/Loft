**Loft now keeps itself up to date.** From this version on, new versions arrive by themselves:

- **Server (standalone download)**: once a day it checks for a new version and downloads it. Admins get a notification, and **Library settings → Loft version → Restart to update** swaps it in. The old version is kept beside it as `loft-server.previous`.
- **Desktop app**: on Windows and as an AppImage it downloads the new version, then asks you to restart now or when you close Loft. On macOS, and from a .deb or .rpm, it tells you a new version is out and opens this page.
- **Android (Loft Lite)**: it downloads the new version and asks. Android shows its own install screen to confirm.
- **Docker and source installs**: you're told a new version is out.

Only Loft's release page on GitHub is checked, and nothing about your library is sent. You can turn checking off in Library settings.

**Coming from 0.1.1?** 0.1.1 can't update itself, so install this version by hand once. Unpack the new server over the old folder, or download the new app. Your library, sign-ins and settings stay as they are.

The same downloads and first-run steps as [0.1.1](https://github.com/Spinjitsudoom/Loft/releases/tag/v0.1.1) apply. Inside the server download, the folder is now just `loft-server`.
