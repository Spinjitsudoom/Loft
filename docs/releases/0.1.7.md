**Reading status, better search, and Loft on ZimaOS.**

**Reading status.** Every book now has a status of your own: Want to read, Not started, Reading, Incomplete, Abandoned or Finished.

- Loft keeps it up to date as you read. Opening a book makes it Reading, and reaching the last page makes it Finished.
- A book left unread turns Incomplete after 15 days and Abandoned after 30. Opening it again makes it Reading.
- Set any status by hand with the new Status button on the book's page. Want to read is the same as the Want to read shelf.
- Home has a new Incomplete row, and Continue reading shows only what you're reading. The stacks filter by every status.

**Search that finds what you mean.** Type the words you remember, in any order, with typos, without apostrophes or hyphens. Search looks in descriptions too, and puts the best matches first.

**Page settings for picture books.** On a picture book's edit page, Pages settings set:

- the reading direction, starting from the book's own;
- the page order: move pages, hide them or add blank ones;
- splitting pages that hold two printed pages;
- the wraparound cover.

Changing a setting doesn't download the book again, and your place and bookmarks stay on their pages.

**Loft on ZimaOS and CasaOS.** Loft's Docker image is now published as `ghcr.io/spinjitsudoom/loft`, for PCs and servers (amd64) and ARM boards such as the Raspberry Pi (arm64).

- To install Loft as a custom app, import `loft-zimaos.yaml` below under **+ → Install a customized app → Import**.
- `loft-compose.yaml` is the same thing for Docker Compose.
- Setup is in [docs/docker.md](https://github.com/Spinjitsudoom/Loft/blob/master/docs/docker.md).

Everything else is as in [0.1.6](https://github.com/Spinjitsudoom/Loft/releases/tag/v0.1.6).
