**Loft backs up your library by itself.**

In **Library settings → Backups**:

- **How often:** every day (the default), every week, or off.
- **How many to keep:** a week of daily backups, then one a week for eight weeks (the default), or the newest 5, 10 or 30.
- **Where:** Loft's data folder until you pick another. Another drive is safer: a backup on the same disk goes with it. Loft leaves a small `.loft-backups` file in the folder you pick; if that drive isn't connected, Loft doesn't back up anywhere else, and tells you.
- **Back up now**, and each backup to **Download** or **Restore**.

A backup holds everything a rescan can't bring back: people, reading progress, shelves, bookmarks, edits and filled-in details, covers you chose, and books waiting for approval. It also holds the lookup keys saved in Library settings, so pick a folder only you can open.

**Restoring** first backs up what's there now, so it can be undone the same way. If it can't finish, nothing changes. Afterwards everyone, you included, signs in again.

Several Lofts can share one backup folder: each one only clears out its own backups, and any of them can be restored.

Everything else is as in [0.1.4](https://github.com/Spinjitsudoom/Loft/releases/tag/v0.1.4).
